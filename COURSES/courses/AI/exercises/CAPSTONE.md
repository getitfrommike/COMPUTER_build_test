# Capstone — Build a Study Assistant

## Scenario
A training organization wants a simple assistant for beginners. Create a working Python command-line prototype using the included offline adapter, with an optional live-model adapter only if approved.

## Required features
1. Accept a topic and a task (`plan`, `quiz`, or a custom third task).
2. Reject blank inputs and inputs beyond the configured length.
3. Show clear instructions and error messages.
4. Label simulated responses so users cannot mistake them for live AI output.
5. Include at least four automated or documented manual tests.
6. Write a short README explaining how to run it and how you would verify outputs.

## Suggested milestones
- 02:45–03:00: Define users and success criteria.
- 03:00–03:30: Implement the assistant and error handling.
- 03:30–03:45: Run tests and fix issues.
- 03:45–04:00: Demonstrate and reflect.

## Scoring (100 points)
| Category | Points |
|---|---:|
| Functionality and reproducibility | 30 |
| Input validation and graceful failures | 20 |
| Evaluation and testing evidence | 20 |
| Transparency, privacy, and responsible use | 20 |
| Demonstration and explanation | 10 |

## Submission
Source code, test output, a 1-page design note, and a short demonstration. Completion acknowledgment is educational, not accredited certification.
