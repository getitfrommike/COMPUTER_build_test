# Guided Practice

## Exercise 1 — Classify the task (5 min)
For each, identify classification, generation, retrieval, or mixed: spam filter; drafting an email; looking up a customer record; summarizing retrieved documentation.

## Exercise 2 — Improve the prompt (10 min)
Rewrite `Tell me about computers` into a prompt with a named audience, scope, word limit, output structure, and uncertainty instruction. Compare two results or describe expected differences if offline.

## Exercise 3 — Test the starter app (15 min)
From `app/`: `python assistant.py` and `python -m unittest -v`. Try `quiz: Python basics`, `plan: learning SQL`, blank input, and a very long input. Document expected vs. actual behavior.

## Exercise 4 — Add a new mode (15 min)
Extend `DemoProvider.respond()` to support `summary:` using a transparent template; label the response as simulated. Add a unit test.

## Exercise 5 — Evaluate reliability (10 min)
Write a five-point rubric for accuracy, usefulness, completeness, privacy, and transparency. Explain how you would independently verify a claim from a live model.

## Instructor note
Timing is flexible within modules. No live model or payment is required.
