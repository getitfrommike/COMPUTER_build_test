# BUILT TO CREATE — Iteration 3 / The Opportunity Engine

Open `index.html` in a desktop or mobile browser. Scroll through the Opportunity Engine section to assemble five flat SVG blueprint modules. The technical illustration is **conceptual**, not a real machine or engineering construction specification.

## Included
- `index.html`: widescreen homepage, five-stage scroll-assembled machine, services, sample pricing, real workstation section and demonstration inquiry form.
- `courses.html`: course navigation and complete Introduction to Databases & SQL workshop landing page ($99 illustrative).
- `app.js`: programmatic, individually controllable SVG engineering modules and scroll animation. No animation libraries required.
- `style.css`: responsive navy/white/electric-blue blueprint styling.
- `assets/`: four actual build photographs recovered from the previous site source.
- `previous_iteration_reference.html`: copy of the prior iteration's HTML for comparison, not used by the new site.

## Important
The inquiry form only prepares copyable text; it does not transmit information. Pricing and course enrollment are examples, not active offers. Before launching, add actual payment and lead handling, service agreements, course schedule and privacy disclosures. Reduced-motion support is included via CSS but scroll movement remains manually controlled. The website is independent of the desktop app and other projects.

## Iteration 3.1 machine artwork
Each of the five modules is now a distinct side-elevation mechanical assembly drawn with native SVG: intake manifold, circular AI processor, relay/logic matrix, software chassis and output turbine. No perspective, no bitmap replacement. Scroll-driven transforms and connectors are retained.

## Iteration 3.2 update
- Larger engineering assembly viewport (up to 570px tall).
- Five modules are on a single fixed horizontal shaft; no vertical scatter.
- Each module starts at 0 opacity and enters in sequence as the visitor scrolls.
- Each module moves horizontally into its exact final position, with connecting couplings appearing at docking milestones.
- Reduced-motion browser preference is respected for CSS motion; scroll position still reveals the drawings.


## Iteration 3.3 — circuit startup
- Each module's own circuit traces illuminate after docking, tied to scroll progress.
- After all five modules connect, the entire assembly enters a restrained blue animated powered-on state.
- Scrolling back reverses docking illumination; reduced-motion users see a static active machine.
- Existing pages, pricing, course page and photos are unchanged.

## Iteration 3.4 — stage keywords
The five module labels now read INFORMATION → INTELLIGENCE → ACTION → PRODUCTS → RESULTS. Each word appears in its stage box as that module scrolls into position; the same word is printed as a technical annotation beneath its machine drawing. The existing circuit activation and scroll assembly remain intact.


### Iteration 3.5 — Finished-machine viewing hold
The machine finishes assembling after 72% of the sticky scroll journey. The remaining 28% holds the complete activated machine in place while the visitor continues scrolling, so it does not immediately disappear. No timer or forced scroll; visitors can stop and inspect it as long as they wish.
